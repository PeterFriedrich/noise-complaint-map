## 4. Technical Learnings

**This container (web session) — see `docs/REMOTE_VM.md`, written this session:**
- No conda, no `.env`, **pytest is not installed**. `pip install -r requirements-ci.txt`.
- No `gh` CLI — GitHub work goes through the `mcp__github__*` tools.
- `data.edmonton.ca` is behind the proxy allowlist, so `pipeline/fetch.py`
  cannot run here. Fix is the owner's, in the environment's network settings.
- Consequence for `.githooks/pre-push`: it shells out to `gh`, so in a web
  container it fails open on its first line — it is a no-op here, not protection.

**Porting adaptations (do not re-derive):**
- Template assumes `src/`, `master`, `.venv`. This repo is `pipeline/`, `main`,
  conda. All three were adapted in the copied files, not left to drift.
- `handoff_gap.py`'s `SUBSTANTIVE` paths deliberately exclude `site/data/` — the
  nightly pipeline rewrites it, so counting it would fire the nag every day over
  work no human did.
- `check_doc_citations.py` excludes `site/` as generated output.
- CI must use `python -m pytest`, not bare `pytest`: the tests do
  `from pipeline.transform import ...`, which only resolves because `-m` puts
  the repo root on `sys.path`.
- `check_decisions_log.py` has `CUTOFF = date(2026, 9, 17)`. Rows dated before it
  are grandfathered — which is why the 6 seeded historical decisions are dated
  `2026-06-20` and pass without citing tests.

**The PR-merge footgun is real, not theoretical.** PR #1 was opened at 21:11Z and
merged by the owner at ~22:58Z while this session was still live. The branch was
reset onto `origin/main` rather than stacked on. This is exactly what
`.githooks/pre-push` exists to catch.

**Verified before committing:** 20 tests pass (17 existing + 3 new),
`check_doc_citations.py` exit 0, `check_decisions_log.py` exit 0,
`handoff_gap.py` correctly reports the gap, `todo_archive.py` runs clean.
